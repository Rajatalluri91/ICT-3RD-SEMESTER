Q. 2. What is a Protocol? (ప్రోటోకాల్ అంటే ఏమిటి?)

  • Each LAN is governed by a protocol, which is an agreed upon format for transmitting data between two devices. ప్రతి LAN ఒక ప్రోటోకాల్ ద్వారా నిర్వహించబడుతుంది. ఇది రెండు పరికరాల మధ్య డేటాను ప్రసారం చేయడానికి అంగీకరించబడిన ఒక ఫార్మాట్/నియమం.
  • There are many standard protocols. Each has particular advantages and disadvantages. అనేక ప్రామాణిక ప్రోటోకాల్‌లు ఉన్నాయి. ప్రతిదానికి నిర్దిష్ట అనుకూలతలు (Advantages) మరియు ప్రతికూలతలు (Disadvantages) ఉంటాయి.
  • Some protocols are simple than others, some are more reliable and some are faster. కొన్ని ప్రోటోకాల్‌లు ఇతర వాటి కంటే సరళంగా ఉంటాయి, కొన్ని మరిన్ని విశ్వసనీయంగా ఉంటాయి మరియు కొన్ని వేగంగా ఉంటాయి.
  • To effectively communicate, a user must have the same protocol installed on that local PC and the remote PC to make a connection. సమర్థవంతంగా కమ్యూనికేట్ చేయడానికి, కనెక్షన్ ఏర్పరచడానికి లోకల్ PC మరియు రిమోట్ PC రెండింటిలోనూ ఒకే ప్రోటోకాల్ ఇన్‌స్టాల్ చేయబడి ఉండాలి.
  • Protocols take the form of software or hardware that must be installed on every computer on the network. ప్రోటోకాల్‌లు సాఫ్ట్‌వేర్ లేదా హార్డ్‌వేర్ రూపంలో నెట్‌వర్క్‌లోని ప్రతి కంప్యూటర్‌లో తప్పనిసరిగా ఇన్‌స్టాల్ చేయబడాలి.
  • Protocols using their own methods, break down data into small packets in preparation for transportation. ప్రోటోకాల్‌లు తమ స్వంత పద్ధతులను ఉపయోగించి, రవాణా/ప్రసారం కోసం డేటాను చిన్న చిన్న ప్యాకెట్లుగా (Packets) విడగొడతాయి.
  • Linking devices pass these packets to the various pieces of equipment, including other computers and printers that are attached to the network. లింకింగ్ పరికరాలు ఈ ప్యాకెట్లను నెట్‌వర్క్‌కు అనుసంధానించబడిన ఇతర కంప్యూటర్లు మరియు ప్రింటర్లతో సహా వివిధ పరికరాలకు చేరవేస్తాయి.
  • A packet is a data segment that includes a header, payload and control elements that are transmitted together. ప్యాకెట్ అనేది ఒక డేటా సెగ్మెంట్, ఇందులో హెడర్ (Header), పేలోడ్ (Payload - అసలు సమాచారం) మరియు కంట్రోల్ ఎలిమెంట్స్ (Control elements) కలిసి ప్రసారం చేయబడతాయి.
  • The receiving computer reconstructs the packets into their original structure. స్వీకరించే కంప్యూటర్ (Receiving computer) ఆ ప్యాకెట్లను మళ్లీ వాటి అసలు రూపంలోకి పునర్నిర్మిస్తుంది.
  • A single LAN may utilize more than one protocol. ఒకే LAN ఒకటి కంటే ఎక్కువ ప్రోటోకాల్‌లను ఉపయోగించవచ్చు.
Common Protocols (సాధారణంగా ఉపయోగించే ప్రోటోకాల్‌లు):
  • 1. TCP/IP: TCP/IP is the protocol of internet and is required on any computer that must communicate across internet. 1. TCP/IP: TCP/IP అనేది ఇంటర్నెట్ ప్రోటోకాల్. ఇంటర్నెట్ ద్వారా కమ్యూనికేట్ చేయాలనుకునే ఏ కంప్యూటర్‌కైనా ఇది తప్పనిసరి.
  • 2. IPX/SPX: It is used in most versions of Novell Netware-which is a networking operating system. 2. IPX/SPX: ఇది నోవెల్ నెట్‌వేర్ (Novell Netware - ఒక నెట్‌వర్కింగ్ ఆపరేటింగ్ సిస్టమ్) యొక్క అనేక వెర్షన్లలో ఉపయోగించబడుతుంది.
  • 3. Net BIOS: This protocol sends messages to every computer that can receive them. It is an excellent protocol for small offices or homes. 3. Net BIOS: ఈ ప్రోటోకాల్ మెసేజ్‌లను స్వీకరించగల ప్రతి కంప్యూటర్‌కు పంపుతుంది. ఇది చిన్న ఆఫీసులు లేదా ఇళ్ల కోసం చాలా ఉపయోగకరమైన ప్రోటోకాల్.

Q. 3. Write about URL (URL గురించి రాయండి)

  • Web page address is a URL. Typing a URL in the location area and hitting the return key will cause the browser to attempt to retrieve that page. వెబ్ పేజీ యొక్క చిరునామానే URL అంటారు. అడ్రస్ బార్ (Location area) లో URL టైప్ చేసి ఎంటర్ కొడితే, బ్రౌజర్ ఆ పేజీని పొందడానికి ప్రయత్నిస్తుంది.
  • If the browser is successful in finding the page, the browser will display it. బ్రౌజర్ ఆ పేజీని కనుగొనడంలో సఫలమైతే, దానిని డిస్ప్లే చేస్తుంది.
  • The URL is designed to incorporate sufficient information. సరిపడా సమాచారాన్ని కలిగి ఉండేలా URL రూపొందించబడింది.
  • Quite naturally, the URL has three parts: (e.g., http://pubpages.uninu.edu/index.html) సాధారణంగా, URL లో మూడు భాగాలు ఉంటాయి: (ఉదాహరణ: http://pubpages.uninu.edu/index.html)
Parts of URL (URL లోని భాగాలు):
  • (1) http : Defines the protocol or schema by which to access the page (Hyper Text Transfer Protocol). This protocol is the set of rules by which an HTML document is transferred over the web. (1) http : పేజీని యాక్సెస్ చేయడానికి ఉపయోగించే ప్రోటోకాల్ లేదా స్కీమాను నిర్వచిస్తుంది. ఈ ప్రోటోకాల్ ఆధారంగా వెబ్‌లో HTML డాక్యుమెంట్లు బదిలీ అవుతాయి.
  • (2) Pubpages.uninu.edu : Identifies the domain name of the computer where the pages resides. The computer is a web server that "serves" web pages. (2) Pubpages.uninu.edu : పేజీలు ఉన్న కంప్యూటర్ యొక్క డొమైన్ నేమ్‌ను గుర్تیస్తుంది. ఈ కంప్యూటర్ అనేది పేజీ రిక్వెస్టులను పూర్తిచేసే ఒక వెబ్ సర్వర్.
  • (3) Index.html : Provides the local name uniquely identifying the specific page. If no name is specified, the server may supply a default file named index.html or Index.HTML. (3) Index.html : నిర్దిష్ట పేజీని ప్రత్యేకంగా గుర్తించే లోకల్ నేమ్‌ను అందిస్తుంది. పేరు ఏదీ పేర్కొనకపోతే, డిఫాల్ట్ ఫైల్ పేరు index.html లేదా Index.HTML అని ఉంటుంది.

Q. 7. What are the major services of Internet? (ఇంటర్నెట్ యొక్క ప్రధాన సేవలు ఏమిటి?)

  • The Internet acts as a carrier for several different services. ఇంటర్నెట్ అనేది అనేక రకాల విభిన్న సేవలను అందించే ఒక మాధ్యమంగా పనిచేస్తుంది.
  • To use any of these services, you need a computer that is connected to the Internet in some way. ఈ సేవలలో దేనినైనా ఉపయోగించడానికి, ఏదో ఒక విధంగా ఇంటర్నెట్‌కు కనెక్ట్ చేయబడిన కంప్యూటర్ అవసరం.
The most commonly used Internet services are:
  • (1) The World Wide Web (WWW)
  • (2) Electronic mail (E-mail)
  • (3) News
  • (4) File Transfer Protocol (FTP)
  • (5) Chat
  • (6) Instant messaging
  • (7) Online Services
  • (8) Peer-to-peer services

Q. 8. What is URL? (URL అంటే ఏమిటి?)

  • The hypertext transfer protocol uses internet addresses in a special format, called a uniform resource locator or URL. హైపర్‌టెక్స్ట్ ట్రాన్స్‌ఫర్ ప్రోటోకాల్ ఇంటర్నెట్ అడ్రస్‌లను ఒక ప్రత్యేక ఫార్మాట్‌లో ఉపయోగిస్తుంది, దీనిని Uniform Resource Locator లేదా URL అంటారు.
  • URLs look like this: type : // address / path URL లు ఈ క్రింది విధంగా కనిపిస్తాయి: type : // address / path
  • In a URL, type specifies the server type, address is the server address, and path is the location/folders within the file structure. URL లో, type అనేది ఫైల్ ఏ సర్వర్‌లో ఉందో నిర్ణయిస్తుంది, address అనేది సర్వర్ అడ్రస్, మరియు path అనేది సర్వర్‌లోని ఫైల్ నిల్వ ఉన్న మార్గాన్ని/ఫోల్డర్‌ను సూచిస్తుంది.

  • www : This site is part of www (ఈ సైట్ World Wide Web లో భాగం).

Q. 22. What are the different types of Browser? (వివిధ రకాల బ్రౌజర్లు ఏవి?)

  • There are two kinds of Browsers: బ్రౌజర్లు ప్రధానంగా రెండు రకాలు:
(1) Textual Browsers (టెక్స్చువల్ బ్రౌజర్లు):
  • Text only browsers such as Lynx and used on Shell accounts. షెల్ ఖాతాలలో (Shell accounts) ఉపయోగించే Lynx వంటి కేవలం వచనాన్ని (Text) మాత్రమే చూపించే బ్రౌజర్లు.
  • This is faster but does not provide GUI features and so not that user friendly. ఇది చాలా వేగంగా ఉంటుంది కానీ GUI (Graphical User Interface) సౌకర్యాలను అందించదు, కాబట్టి వినియోగదారులకు అంత సులభంగా ఉండదు.
(2) Graphical Web Browsers (గ్రాఫికల్ వెబ్ బ్రౌజర్లు):
  • Graphical Web Browsers such as Netscape Navigator, Internet Explorer are more popular. Hot Java and Mosaic are also Web browsers. నెట్‌స్కేప్ నేవిగేటర్, ఇంటర్నెట్ ఎక్స్‌ప్లోరర్ వంటి గ్రాఫికల్ వెబ్ బ్రౌజర్లు చాలా ప్రసిద్ధమైనవి. హాట్ జావా మరియు మొజాయిక్ కూడా వెబ్ బ్రౌజర్లే.
  • These browsers provide you with Inline images, fonts and document layouts. ఈ బ్రౌజర్లు ఇన్-లైన్ ఇమేజెస్ (చిత్రాలు), విభిన్న ఫాంట్‌లు మరియు డాక్యుమెంట్ లేఅవుట్‌లతో సమాచారాన్ని అందిస్తాయి.
