Q. 11. How to create new files using Google drive ? Explain creating new documents.

గూగుల్ డ్రైవ్ ఉపయోగించి కొత్త ఫైళ్లను ఎలా సృష్టించాలి?

1. Accessing Google Drive / గూగుల్ డ్రైవ్‌లోకి లాగిన్ అవ్వడం

  • To use Google Drive, you can sign in with an existing Google account or create one. గూగుల్ డ్రైవ్‌ను ఉపయోగించడానికి మీ వద్ద ఉన్న గూగుల్ ఖాతాతో లాగిన్ కావచ్చు లేదా కొత్త ఖాతాను సృష్టించుకోవచ్చు.
  • Since it's cloud-based, you can access your files from any device just by logging into your Google account and going to drive.google.com. ఇది క్లౌడ్ ఆధారితమైనది కావడంతో, మీ గూగుల్ ఖాతాలోకి లాగిన్ అయి drive.google.com వెబ్‌సైట్‌కి వెళ్లడం ద్వారా ఏ పరికరం (Device) నుండైనా మీ ఫైళ్లను యాక్సెస్ చేయవచ్చు.

2. Steps to Create a New File / కొత్త ఫైల్‌ను సృష్టించే దశలు

  1. Click the red "NEW" button in the left sidebar. ఎడమ సైడ్‌బార్‌లో ఉన్న ఎరుపు రంగు "NEW" బటన్‌పై క్లిక్ చేయండి.
  2. Choose which file type you wish to create (e.g., Folder, File upload, Google Docs, Google Sheets, Google Slides). మీరు సృష్టించాలనుకుంటున్న ఫైల్ రకాన్ని ఎంచుకోండి (ఉదాహరణకు: ఫోల్డర్, ఫైల్ అప్‌లోడ్, గూగుల్ డాక్స్, గూగుల్ షీట్స్, గూగుల్ స్లైడ్స్).
Diagram: Google Drive "NEW" Menu & File Selection UI

3. Opening & Working on the Document / ఫైల్ ఓపెన్ చేయడం మరియు పనిచేయడం

  • Your file will open in a new browser tab and you can start working on it immediately. మీరు ఎంచుకున్న ఫైల్ బ్రౌజర్‌లోని ఒక కొత్త ట్యాబ్‌లో ఓపెన్ అవుతుంది మరియు మీరు వెంటనే దానిపై పనిచేయడం ప్రారంభించవచ్చు.
  • The Google Docs editor features standard menu bar options including: File, Edit, View, Insert, Format, Tools, Table, Add-ons, Help. గూగుల్ డాక్స్ ఎడిటర్‌లో సాధారణ మెనూ బార్ ఆప్షన్‌లు ఉంటాయి: File, Edit, View, Insert, Format, Tools, Table, Add-ons, Help.

4. Naming / Renaming the Document / ఫైల్‌కు పేరు పెట్టడం

  • Give your file a name by clicking where it says "Untitled Document" (or Spreadsheet, etc.) in the upper left corner. ఎగువ ఎడమ మూలన "Untitled Document" (లేదా Spreadsheet మొదలైనవి) అని ఉన్న చోట క్లిక్ చేసి మీ ఫైల్‌కు కావలసిన పేరును ఇవ్వండి.
  • Type the new title for your document and press Enter to save the name. మీ డాక్యుమెంట్ కోసం కొత్త పేరును టైప్ చేసి, ఆ పేరును సేవ్ చేయడానికి Enter నొక్కండి.
