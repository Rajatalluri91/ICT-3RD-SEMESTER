Q. 2. Write about classification of computer viruses and worms.

కంప్యూటర్ వైరస్‌లు మరియు వర్మ్స్ వర్గీకరణ.

1. Introduction / పరిచయం

  • Computer Viruses are classified according to their nature of infection and behavior. Different types of computer virus classification are given below. కంప్యూటర్ వైరస్‌లు ఇన్ఫెక్షన్ కలిగించే స్వభావం మరియు ప్రవర్తన ఆధారంగా వర్గీకరించబడతాయి. వివిధ రకాల కంప్యూటర్ వైరస్ వర్గీకరణలు క్రింద ఇవ్వబడ్డాయి.

2. Classification of Computer Viruses / కంప్యూటర్ వైరస్‌ల వర్గీకరణ

(a) Boot Sector Virus / బూట్ సెక్టర్ వైరస్:
  • A Boot Sector Virus infects the first sector of the hard drive, where the Master Boot Record (MBR) is stored. The Master Boot Record (MBR) stores the disk's primary partition table and to store bootstrapping instructions which are executed after the computer's BIOS passes execution to machine code. బూట్ సెక్టర్ వైరస్ మాస్టర్ బూట్ రికార్డ్ (MBR) నిల్వ చేయబడిన హార్డ్ డ్రైవ్ యొక్క మొదటి సెక్టార్‌ను ఇన్ఫెక్ట్ చేస్తుంది. MBR అనేది డిస్క్ ప్రాథమిక పార్టిషన్ పట్టికను మరియు బూట్‌స్ట్రాపింగ్ సూచనలను నిల్వ చేస్తుంది.
  • If a computer is infected with Boot Sector Virus, when the computer is turned on, the virus launches immediately and is loaded into memory, enabling it to control the computer. కంప్యూటర్ ఆన్ చేసిన వెంటనే ఈ వైరస్ వెంటనే రన్ అయి మెమరీలోకి లోడ్ అవుతుంది, తద్వారా కంప్యూటర్‌ను తన నియంత్రణలోకి తీసుకుంటుంది.
(b) File Deleting Viruses / ఫైల్ డిలీటింగ్ వైరస్‌లు:
  • A File Deleting Virus is designed to delete critical files which are the part of Operating System or data files. ఆపరేటింగ్ సిస్టమ్‌లో భాగమైన ముఖ్యమైన ఫైళ్లను లేదా డేటా ఫైళ్లను తొలగించడానికి ఇది రూపొందించబడింది.
(c) Mass Mailer Viruses / మాస్ మెయిలర్ వైరస్‌లు:
  • Mass Mailer Viruses search e-mail programs like MS outlook for e-mail addresses which are stored in the address book and replicate by e-mailing themselves to the addresses stored in the address book of the e-mail program. MS Outlook వంటి ఈ-మెయిల్ ప్రోగ్రామ్‌లలోని అడ్రస్ బుక్‌లో ఉన్న ఈ-మెయిల్ అడ్రస్‌లను వెతికి, ఆ అడ్రస్‌లకు తమను తాము ఈ-మెయిల్ చేసుకుంటూ వ్యాపిస్తాయి.
(d) Macro Viruses / మ్యాక్రో వైరస్‌లు:
  • Macro viruses are written by using the Macro programming languages like VBA, which is a feature of MS office package. A macro is a way to automate and simplify a task that you perform repeatedly in MS office suit (MS Excel, MS Word etc). MS Office ప్యాకేజీలోని VBA వంటి మ్యాక్రో ప్రోగ్రామింగ్ భాషలను ఉపయోగించి ఇవి రాయబడతాయి. MS Excel, MS Wordలలో పునరావృతమయ్యే పనులను స్వయంచాలకం చేయడానికి మ్యాక్రోలు ఉపయోగపడతాయి.
  • These macros are usually stored as part of the document or spreadsheet and can travel to other systems when these files are transferred to another computers. ఈ మ్యాక్రోలు డాక్యుమెంట్ లేదా స్ప్రెడ్‌షీట్‌లో భాగంగా నిల్వ చేయబడతాయి, మరియు ఈ ఫైళ్లను ఇతర కంప్యూటర్లకు పంపినప్పుడు అక్కడికి వ్యాపిస్తాయి.
(e) Polymorphic Viruses / పాలిమార్ఫిక్ వైరస్‌లు:
  • Polymorphic Viruses have the capability to change their appearance and change their code every time they infect a different system. This helps the Polymorphic Viruses to hide from anti-virus software. ఇవి వేర్వేరు సిస్టమ్‌లను ఇన్ఫెక్ట్ చేసిన ప్రతిసారీ తమ రూపాన్ని మరియు కోడ్‌ను మార్చుకునే సామర్థ్యాన్ని కలిగి ఉంటాయి. ఇది యాంటీ-వైరస్ సాఫ్ట్‌వేర్ నుండి దాక్కోవడానికి సహాయపడుతుంది.
(f) Armored Viruses / ఆర్మర్డ్ వైరస్‌లు:
  • Armored Viruses are type of viruses that are designed and written to make itself difficult to detect or analyze. An Armored Virus may also have the ability to protect itself from antivirus programs, making it more difficult to disinfect. తమను గుర్తించడం లేదా విశ్లేషించడం కష్టమయ్యేలా ఇవి డిజైన్ చేయబడతాయి. యాంటీవైరస్ ప్రోగ్రామ్‌ల నుండి తమను తాము రక్షించుకునే సామర్థ్యాన్ని కలిగి ఉండి, తొలగించడాన్ని సవాలుగా మారుస్తాయి.
(g) Stealth Viruses / స్టెల్త్ వైరస్‌లు:
  • Stealth viruses have the capability to hide from operating system or anti-virus software by making changes to file sizes or directory structure. Stealth viruses are anti-heuristic nature which helps them to hide from heuristic detection. ఫైల్ సైజులు లేదా డైరెక్టరీ నిర్మాణంలో మార్పులు చేయడం ద్వారా ఆపరేటింగ్ సిస్టమ్ లేదా యాంటీ-వైరస్ నుండి దాక్కుంటాయి. ఇవి హ్యూరిస్టిక్ డిటెక్షన్ నుండి తప్పించుకోగలవు.
(h) Polymorphic Viruses (Mutation Feature) / మ్యుటేషన్ ఫీచర్:
  • Polymorphic viruses change their form in order to avoid detection and disinfection by anti-virus applications. After the work, these types of viruses try to hide from the anti-virus application by encrypting parts of the virus itself. This is known as mutation. గుర్తింపును నివారించడానికి ఇవి రూపాంతరం చెందుతాయి. పని పూర్తయిన తర్వాత వైరస్ భాగాన్ని ఎన్క్రిప్ట్ చేసి దాక్కుంటాయి, దీనిని మ్యుటేషన్ అంటారు.
(i) Retrovirus / రెట్రోవైరస్:
  • Retrovirus is another type virus which tries to attack and disable the anti-virus application running on the computer. A retrovirus can be considered anti-antivirus. Some Retroviruses attack the anti-virus application and stop it from running or some other destroys the virus definition database. కంప్యూటర్‌లో రన్ అయ్యే యాంటీ-వైరస్ అప్లికేషన్‌పైనే దాడి చేసి దాన్ని నిలిపివేయడానికి ప్రయత్నించే వైరస్ ఇది. ఇవి యాంటీవైరస్ ప్రోగ్రామ్‌ను ఆపివేయడం లేదా వైరస్ డెఫినిషన్ డేటాబేస్‌ను నాశనం చేయడం చేస్తాయి.
(j) Multiple Characteristic Viruses / మల్టిపుల్ క్యారెక్టరిస్టిక్ వైరస్‌లు:
  • Multiple Characteristic viruses has different characteristics of viruses and have different capabilities. వివిధ రకాల వైరస్ లక్షణాలను మరియు విభిన్న సామర్థ్యాలను ఒకేసారి కలిగి ఉండే వైరస్‌లు ఇవి.

3. Classification of Computer Worms / కంప్యూటర్ వర్మ్స్ వర్గీకరణ

  • A worm has similar characteristics of a virus. Worms are also self-replicating, but self-replication of a worm is in a different way. Worms are standalone and when it is infected on a computer, it searches for other computers connected through a local area network (LAN) or Internet connection. వర్మ్ కూడా వైరస్ లాంటి లక్షణాలనే కలిగి ఉంటుంది, కానీ స్వయం-పునరావృతం వేరే విధంగా ఉంటుంది. ఇది స్వతంత్రమైనది; కంప్యూటర్‌లోకి ప్రవేశించగానే LAN లేదా ఇంటర్నెట్ ద్వారా అనుసంధానించబడిన ఇతర కంప్యూటర్ల కోసం వెతుకుతుంది.
  • When a worm finds another computer, it replicates itself to the new computer and continues to search for other computers on the network to replicate. మరొక కంప్యూటర్ లభించగానే దానికి వ్యాపించి, నెట్‌వర్క్‌లోని ఇతర కంప్యూటర్ల కోసం వెతకడం కొనసాగిస్తుంది.
  • Due to the nature of replication through the network, a worm normally consumes much system resources including network bandwidth, causing network servers to stop responding. నెట్‌వర్క్ ద్వారా వ్యాపించడం వల్ల ఇవి బ్యాండ్‌విడ్త్‌తో సహా ఎక్కువ సిస్టమ్ వనరులను వినియోగించుకుని, నెట్‌వర్క్ సర్వర్లు పనిచేయకుండా చేస్తాయి.
Different types of Computer Worms are / వర్మ్స్ రకాలు:
(a) Email Worms / ఈమెయిల్ వర్మ్స్:
  • Email Worms spread through infected email messages as an attachment or a link of an infected website. ఇన్ఫెక్ట్ అయిన ఈమెయిల్ మెసేజ్‌లు, అటాచ్‌మెంట్‌లు లేదా లింక్‌ల ద్వారా ఇవి వ్యాపిస్తాయి.
(b) Instant Messaging Worms / ఇన్‌స్టంట్ మెసేజింగ్ వర్మ్స్:
  • Instant Messaging Worms spread by sending links to the contact list of instant messaging applications. ఇన్‌స్టంట్ మెసేజింగ్ యాప్‌లలోని కాంటాక్ట్ లిస్ట్‌కు లింక్‌లను పంపడం ద్వారా వ్యాపిస్తాయి.
(c) Internet Worms / ఇంటర్నెట్ వర్మ్స్:
  • Internet worm will scan all available network resources using local operating system services and/or scan the Internet for vulnerable machines. If a computer is found vulnerable it will attempt to connect and gain access to them. ఇంటర్నెట్ వర్మ్‌లు లభ్యమయ్యే నెట్‌వర్క్ వనరులను, బలహీనంగా ఉన్న సిస్టమ్‌లను స్కాన్ చేసి, వాటితో కనెక్ట్ అయి యాక్సెస్ పొందడానికి ప్రయత్నిస్తాయి.
(d) IRC Worms / IRC వర్మ్స్:
  • IRC Worms spread through IRC chat channels, sending infected files or links to infected websites. IRC చాట్ ఛానెళ్ల ద్వారా ఇన్ఫెక్ట్ అయిన ఫైళ్లు లేదా లింక్‌లను పంపడం ద్వారా ఇవి వ్యాపిస్తాయి.
(e) File-sharing Networks Worms / ఫైల్-షేరింగ్ నెట్‌వర్క్స్ వర్మ్స్:
  • Worms place a copy of them in a shared folder and spread via P2P network. ఇవి షేర్డ్ ఫోల్డర్‌లో తమ కాపీని ఉంచి P2P నెట్‌వర్క్ ద్వారా వ్యాపిస్తాయి.
