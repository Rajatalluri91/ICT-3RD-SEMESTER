Q. 5. What is hacking? Write about the techniques.

హ్యాకింగ్ అంటే ఏమిటి? దాని సాంకేతిక పద్ధతులను వివరించండి.

1. What is Hacking? / హ్యాకింగ్ అంటే ఏమిటి?

  • Hacking refers to unauthorized access or intrusion into a computer system or network to bypass security features or alter functionality. హ్యాకింగ్ అనగా ఒక కంప్యూటర్ సిస్టమ్ లేదా నెట్‌వర్క్‌లోకి అనుమతి లేకుండా ప్రవేశించి, దాని సెక్యూరిటీని అధిగమించడం లేదా ఫంక్షనాలిటీని మార్చడం.
  • The individual performing these unauthorized activities is known as a Hacker. ఈ అనుమతి లేని కార్యకలాపాలను నిర్వహించే వ్యక్తినే హ్యాకర్ (Hacker) అని పిలుస్తారు.

2. Common Hacking Techniques (Part 1) / హ్యాకింగ్ పద్ధతులు (భాగం 1)

1. Phishing / ఫిషింగ్:
  • A technique using fraudulent emails or fake websites to trick users into revealing sensitive data like credit card details and passwords. వినియోగదారులను మోసం చేసి పాస్‌వర్డ్‌లు, క్రెడిట్ కార్డ్ వివరాల వంటి రహస్య సమాచారాన్ని సేకరించడానికి నకిలీ ఈమెయిళ్లు లేదా వెబ్‌సైట్‌లను వాడే పద్ధతి.
2. Viruses and Malicious Code / వైరస్‌లు మరియు మాల్వేర్:
  • Hackers deploy malicious scripts or software into target databases to extract information or corrupt files. డేటాబేస్‌ల నుండి సమాచారాన్ని దొంగిలించడానికి లేదా ఫైళ్లను నాశనం చేయడానికి హ్యాకర్లు హానికరం ఐన కోడ్ లేదా సాఫ్ట్‌వేర్‌ను ప్రవేశపెడతారు.
3. UI Redress (Clickjacking) / యుఐ రెడ్రెస్:
  • Involves creating hidden, transparent interfaces over legitimate buttons so users perform unintended actions. అసలైన బటన్‌ల పైన కంటికి కనిపించని నకిలీ ఇంటర్‌ఫేస్‌ను ఉంచి, యూజర్లు తెలియకుండా వేరే చర్యలు చేసేలా మోసం చేసే విధానం.
4. Cookie Theft / కుకీ థెఫ్ట్:
  • Stealing browser cookies using malicious code to access browsing history, usernames, and active session tokens. బ్రౌజర్ కుకీలను దొంగిలించడం ద్వారా వినియోగదారుల లాగిన్ సెషన్లు, బ్రౌజింగ్ హిస్టరీ మరియు పాస్‌వర్డ్‌లను హ్యాక్ చేయడం.

3. Common Hacking Techniques (Part 2) / హ్యాకింగ్ పద్ధతులు (భాగం 2)

5. Denial of Service (DoS / DDoS) / డినైయల్ ఆఫ్ సర్వీస్:
  • Flooding a server with massive fake traffic using botnets to crash the website and make it unavailable to real users. బాట్‌నెట్ నెట్‌వర్క్ ద్వారా సర్వర్‌పైకి విపరీతమైన నకిలీ ట్రాఫిక్‌ను పంపి, అది క్రాష్ అయ్యేలా చేసి అసలైన యూజర్లకు సేవలు అందకుండా చేయడం.
6. DNS Spoofing / డిఎన్ఎస్ స్పూఫింగ్:
  • Corrupting Domain Name System cache data to redirect traffic from a genuine site to a fake malicious webpage. డిఎన్ఎస్ క్యాష్ డేటాను మార్చడం ద్వారా వినియోగదారులను నిజమైన వెబ్‌సైట్ నుండి హ్యాకర్లు తయారు చేసిన నకిలీ సైట్‌కి మళ్లించడం.
7. SQL Injection / ఎస్క్యూఎల్‌ ఇంజెక్షన్:
  • Injecting malicious SQL commands into vulnerable website input fields to gain unauthorized database access. వెబ్‌సైట్ ఇన్‌పుట్ ఫీల్డ్‌లలోకి హానికరం ఐన SQL కోడ్‌ను పంపి డేటాబేస్‌లోని రహస్య సమాచారాన్ని యాక్సెస్ చేయడం.

4. Advanced Hacking Techniques / అధునాతన హ్యాకింగ్ పద్ధతులు

8. Keylogger Injection / కీలాగర్ ఇంజెక్షన్:
  • Installing malware that records all keystrokes typed by the user, sending login credentials directly to the hacker. యూజర్ కీబోర్డుపై టైప్ చేసే ప్రతీ అక్షరాన్ని రికార్డు చేసే సాఫ్ట్‌వేర్‌ను ప్రవేశపెట్టి, పాస్‌వర్డ్‌లను దొంగిలించడం.
9. Non-targeted Website Hack / నాన్-టార్గెటెడ్ వెబ్‌సైట్ హ్యాక్:
  • Scanning thousands of sites automatically for known vulnerabilities in CMS plugins or templates to breach them. ఏదైనా నిర్దిష్ట వెబ్‌సైట్‌ను కాకుండా, బలహీనంగా ఉన్న ఏ వెబ్‌సైట్‌నైనా ఆటోమేటిక్ టూల్స్ ద్వారా వెతికి హ్యాక్ చేయడం.
10. Brute Force Attack / బ్రూట్ ఫోర్స్ ఎటాక్:
  • Automated trial and error of millions of username and password combinations until the correct key is found. సరైన పాస్‌వర్డ్ దొరికే వరకు సాఫ్ట్‌వేర్ సహాయంతో వేలాది పాస్‌వర్డ్ కాంబినేషన్‌లను ఒకదాని తర్వాత ఒకటి నిరంతరం ప్రయత్నించడం.
